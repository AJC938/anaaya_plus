# Anaaya Plus — Portfolio Documentation

Anaaya Plus is a Flutter-based automotive service platform prototype developed as a software engineering portfolio project. This documentation hub is reserved for the project's public-facing architecture, testing evidence, screenshots, and demonstration materials.

## Project status

- Functional scope: complete for the current test/portfolio release.
- Payment: local test simulation only; no real money is processed.
- SMS/OTP: zero-cost test configuration; no production SMS delivery is claimed.
- Primary platform tested: Android emulator.
- iOS real-device validation: not part of the current release evidence.

## Evidence

- See `docs/screenshots/` for curated UI captures.
- See `docs/testing/` for final test evidence.
- See `docs/architecture/` for system architecture documentation.
- The demo video is intentionally hosted outside the repository because the source recording exceeds GitHub's normal single-file size limit.

## Documentation principles

The public documentation describes what is implemented and verified in the repository. It does not claim production payment processing, production SMS delivery, or commercial deployment readiness.
