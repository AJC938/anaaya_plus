# Changelog

All notable project changes are documented here.

## [Unreleased]

- Repository documentation and portfolio structure are being formalized.

## [Initial Portfolio Release]

- Flutter customer-facing automotive service booking flow.
- Phone/OTP authentication flow using Supabase Edge Functions and Firebase Custom Token sign-in.
- Vehicle management.
- Service catalog and dynamic service options/pricing.
- Saved locations, current-location detection, and map selection.
- Slot-based scheduling with Firestore-backed booking state.
- Local payment simulation.
- Simulated technician-dispatch tracking lifecycle.
- Firebase Cloud Messaging notifications.
- Arabic RTL and English LTR localization.
- Automated Flutter and Deno tests.
